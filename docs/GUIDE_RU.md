# Подробное руководство пользователя и разработчика BlenderNVDA (Русский)

## 1. Зачем создан BlenderNVDA

Обычный интерфейс Blender не использует стандартные элементы управления Windows (Win32 / UI Automation), поэтому программы экранного доступа (NVDA, JAWS) не могут читать кнопки, вкладки, меню, списки и тем более понимать форму 3D-объектов в сцене.

**BlenderNVDA** — это гибридный нативный мост для **Blender 5.2 LTS (Windows x64) + NVDA**, состоящий из двух частей:
1. **C++ библиотека `blender_nvda_accessibility.dll`:**
   - При старте Blender быстро загружает предсобранный кэш смещений функций (`blender_nvda_symbols.cache`, версия `3`, `33` символа из `blender.pdb`).
   - Ставит лёгкие перехватчики на отрисовку текста (`BLF_draw`, `BLF_draw_mono`), виджетов (`ui::draw_button`), пунктов поиска (`ui::draw_menu_item`), сворачиваемых панелей (`ui::draw_aligned_panel`), списка файлов (`file_draw_list`), фокуса кнопок (`ui::button_activate_over`) и оконной процедуры (`GHOST_SystemWin32::s_wndProc`).
   - Вся речь отправляется в `nvdaControllerClient64.dll` из отдельного фонового потока Win32 (`NvdaSpeechEngine`), не блокируя отрисовку интерфейса.
   - Нажатие кнопок, чекбоксов, вкладок, полей ввода и сворачиваемых панелей идёт **напрямую по внутренним указателям Blender** на главном потоке (`WM_APP_NVDA_ACTIVATE` → `Hook_s_wndProc` → `ExecutePendingUiAction()`), без перемещения системного курсора мыши и без `SendInput`.
2. **Модульный Python-пакет (`blender_nvda_autoload.py` + `nvda_modules/`):**
   - `bridge.py` — загрузка DLL, озвучка, хранение состояния 3D-навигации, расчёт габаритов и контактов.
   - `nav_3d.py` — пошаговое перемещение по 3D-сцене, захват деталей, поворот взгляда/объектов, радар, окно точных границ «От и До», метки объектов и частей (`Vertex Groups`).
   - `shape_scanner.py` — математический RAM-сканер формы 3D-объектов без шаблонов (читает геометрию напрямую из памяти Blender).
   - `camera_light.py` — анализ конуса камеры, попадания объектов в кадр, направления лучей источников света, теней на полу и быстрый рендер.
   - `workspaces_ui.py` — быстрое переключение рабочих пространств (Workspaces) и вкладок Свойств (`Shift+P` / `P`).

## 2. Установка, обновление и удаление

### Вариант А: готовая сборка из ветки `compiled`
1. Скачайте ветку `compiled` репозитория `BlenderNVDA` и распакуйте её в любую папку.
2. Закройте все открытые окна **Blender** (чтобы DLL не была занята старым процессом).
3. Запустите **`BlenderNVDAInstaller.exe`**.
   - Установщик найдёт установленный `Blender 5.2` в стандартных папках `Program Files\Blender Foundation`, скопирует `blender_nvda_accessibility.dll`, `nvdaControllerClient64.dll`, `blender_nvda_autoload.py` и `nvda_modules/` в `%APPDATA%\Blender Foundation\Blender\5.2\scripts\startup`, очистит `__pycache__` и заранее создаст файл `blender_nvda_symbols.cache`.
4. Откройте Blender при запущенном NVDA.

### Вариант Б: сборка из исходников (ветка `main`)
Требуется компилятор **MinGW-w64 (`g++` с поддержкой C++17)** и файл `nvdaControllerClient64.dll` из официального NVDA Controller Client SDK:
```powershell
g++ -O2 -s -shared -std=c++17 -Wall -Wextra -static -static-libgcc -static-libstdc++ `
    blender_nvda_accessibility.cpp -o blender_nvda_accessibility.dll -luser32 -lkernel32

g++ -O2 -s -std=c++17 -municode -Wall -Wextra -static -static-libgcc -static-libstdc++ `
    BlenderNVDAInstaller.cpp -o BlenderNVDAInstaller.exe -lshell32 -luser32 -lkernel32
```
Положите `nvdaControllerClient64.dll` рядом с собранными файлами и запустите `.\BlenderNVDAInstaller.exe`.

### Параметры командной строки `BlenderNVDAInstaller.exe`
- Без параметров — установка / обновление адаптации и сборка кэша символов.
- `--rescan` — принудительная пересборка `blender_nvda_symbols.cache` (нужна, если вы обновили Blender, например, с `5.2.3` до `5.2.4`).
- `--uninstall` — удаление скриптов, модулей, DLL и кэша из профиля Blender.

## 3. Навигация по 4 зонам интерфейса (`F6`)

Весь интерфейс Blender логически разделён на **4 главные зоны**, между которыми вы переключаетесь клавишами **`F6`** (вперёд) и **`Shift+F6`** (назад):

1. **Зона 0 — `3D-сцена` (`SPACE_VIEW3D`):**
   - Основной режим строительства, перемещения, осмотра, сканирования форм, работы со светом и камерой.
   - Фоновые перерисовки боковых панелей и левой панели инструментов в этой зоне **заглушены**, чтобы ничто не перебивало вашу работу.
2. **Зона 1 — `Список объектов сцены` (`SPACE_OUTLINER`):**
   - `Стрелка Вверх` / `Вниз` — перебор элементов Outliner (и объектов сцены).
   - `Enter` / `Пробел` — прямое нажатие выбранного элемента.
3. **Зона 2 — `Настройки и свойства` (`SPACE_PROPERTIES`, а также `Preferences`, `Shader/Node Editor` и др.):**
   - **`Стрелка Влево` / `Вправо`** — прямое переключение вкладок Свойств (`Инструмент`, `Рендер`, `Вывод`, `Слой визуализации`, `Сцена`, `Мир`, `Коллекция`, `Объект`, `Модификаторы`, `Частицы`, `Физика`, `Ограничители`, `Данные`, `Материал` и др.). При смене вкладки список пунктов автоматически очищается от элементов предыдущей вкладки.
   - **`Стрелка Вверх` / `Вниз` / `Tab` / `Shift+Tab`** — движение по всем пунктам активной вкладки, включая **заголовки сворачиваемых панелей** (`Панель: Гравитация (свёрнута)`) и пункты, находящиеся ниже видимой прокрутки.
   - **`Enter` / `Пробел`** — прямое выполнение без движения мыши:
     - на заголовке `Панель: ...` — раскрывает или сворачивает панель и сразу озвучивает новое состояние;
     - на галочке (`(включено)` / `(выключено)`) — мгновенно переключает её;
     - на кнопке действия (`Создать`, `Удалить`, `Добавить...`) — запускает оператор;
     - на выпадающем списке или поповере — открывает меню выбора;
     - на числовом или текстовом поле — включает ввод значения с клавиатуры (подтверждение — `Enter`, отмена — `Escape`).
4. **Зона 3 — `Верхнее меню и заголовки` (`SPACE_TOPBAR` и заголовки редакторов):**
   - `Стрелки` — проход по пунктам (`Файл`, `Правка`, `Рендер`, `Окно`, `Справка`, вкладки рабочих пространств и др.).
   - `Enter` / `Пробел` — открытие меню или переключение раздела.

### Всплывающие меню, диалоги и особые окна
- **`Shift+A` (Добавить объект), `Shift+P` (Разделы и вкладки), `F3` (Поиск), контекстные меню:**
  - Активность меню определяется напрямую по живым временным регионам Blender (`RGN_TYPE_TEMPORARY`) — меню **не обрывается по таймеру**, даже если вы делаете паузы или быстро листаете стрелками.
  - Переход по пунктам — `Стрелки Вверх/Вниз/Влево/Вправо`, подтверждение — `Enter`, закрытие — `Escape`.
- **Диалоговые окна (`N` — «От и До», `L` — «Метка», `F9` — параметры последнего действия):**
  - `Стрелки Вверх/Вниз` или `Tab` / `Shift+Tab` — перемещение по полям и кнопкам.
  - `Enter` / `Пробел` — вход в редактирование поля или нажатие кнопки (`OK` и др.). Во время ввода текста повторный `Enter` фиксирует значение.
- **Проводник файлов (`Ctrl+S`, `Ctrl+O` — `SPACE_FILE`):**
  - Стрелки, `PageUp`/`PageDown`, `Home`/`End`, `Enter` и `Backspace` проходят напрямую в нативный список файлов Blender; `Tab` / `Shift+Tab` позволяет пройти по остальным кнопкам и полям окна.
- **Настройки (`Preferences` — `SPACE_USERPREF`):**
  - Автоматически перехватываются в режим навигации Зоны 2 (`Влево`/`Вправо` — разделы настроек, `Вверх`/`Вниз` — параметры, `Enter`/`Пробел` — изменить).
- **Подсказки (`F1` или `F5`):**
  - В любой зоне озвучивают полную встроенную справку Blender для текущего выбранного элемента.
- **`Escape`:**
  - Закрывает открытое меню/диалог, сбрасывает активный ввод и возвращает фокус в `3D-сцену` (`Зона 0`).

## 4. Полный справочник команд в `3D-сцене` (Зона 0)

### Перемещение и шаг
- **`Стрелка Вверх` / `Вниз` / `Влево` / `Вправо`** — шаг вперёд, назад, влево, вправо относительно текущего горизонтального направления взгляда. Если деталь взята в руки (`E`), она перемещается вместе с 3D-курсором с автоматической проверкой касаний, стыковки вплотную и пересечений с другими объектами.
- **`PageUp` / `PageDown`** — шаг вверх / вниз по оси `Z`.
- **`Shift + Стрелки` / `Shift + PageUp` / `Shift + PageDown`** — точный микрошаг (в `10` раз меньше текущего шага).
- **`[` или `-`** — уменьшить размер шага по сетке пресетов.
- **`]` или `=`** — увеличить размер шага по сетке пресетов.

### Осмотр, координаты и работа с объектами
- **`C`** — озвучить текущие координаты 3D-курсора (`X, Y, Z`), направление и наклон взгляда, текущий шаг, а также статус, границы (`От ... до ...`) и размеры активного/взятого объекта.
- **`E`** — захватить ближайший (или активный) объект в руки; повторное нажатие `E` ставит деталь на место и сообщает точные мировые границы и контакт/стыковку с соседними объектами.
- **`F`** — радар «Что передо мной»: озвучивает объекты прямо по курсу и вокруг вас с расстоянием и направлением.
- **`Shift+F`** — открывает меню списка всех объектов сцены для мгновенного прыжка к выбранному объекту.
- **`Alt + Стрелки`** — повернуть взгляд (если ничего не захвачено) или повернуть захваченную деталь / активную камеру / источник света с озвучкой нового направления.
- **`Alt + Shift + Стрелки`** — изменить масштаб захваченной детали; если выбрана камера — изменить угол обзора (фокусное расстояние), если источник света — изменить мощность.
- **`N`** — открыть диалог точных границ **«От и До»** (`От X`..`До X`, `От Y`..`До Y`, `От Z`..`До Z`, шаг перемещения и шаг поворота). После подтверждения деталь автоматически принимает заданные габариты и встаёт точно в указанный диапазон координат.
- **`Delete`** — удалить активный объект (в Object Mode).
- **`Tab`** — переключиться между `Объектным режимом` (`Object Mode`) и `Режимом редактирования` (`Edit Mode`).
- **`,` / `.`** (`Shift+,` / `Shift+.`) — шаг назад / вперёд по кадрам анимации (`±1` кадр или `±10` кадров с `Shift`).

### Пользовательские метки деталей (`L`)
- **В Object Mode (`L`):** задаёт понятное пользовательское имя/метку самому объекту (хранится в его свойствах `.blend`).
- **В Edit Mode (`L`, при выделенных вершинах):** сохраняет выделенную часть геометрии как стандартную группу вершин (`Vertex Group`) с вашим названием (например, «Уступ», «Ручка», «Крышка»). При последующем сканировании `V` / `Shift+V` сканер сам считает эту часть из ОЗУ и назовёт её расположение и габариты.

### Математический RAM-сканер формы (`V` и `Shift+V`)
В отличие от «эхолокации», сканер читает итоговую геометрию объекта (с учётом модификаторов) **напрямую из оперативной памяти Blender**:
- **`V` (описательный скан формы):**
  - Работает для всех типов объектов: `MESH`, `CURVE`, `SURFACE`, `META`, `FONT` (Текст), `LIGHT`, `CAMERA`, `ARMATURE`, `LATTICE`, `EMPTY`, `SPEAKER`.
  - Определяет базовый профиль (куб, шар, цилиндр/столб, конус/пирамида, бочка, тор со сквозным отверстием, полый стакан/чаша с глубиной и толщиной стенок, изогнутый открытый лист/поверхность, замкнутая или разомкнутая кривая, текстовый объект).
  - Без хардкода шаблонов вычисляет **рельеф, выступы и впадины по 6 сторонам** (Принцип А), **ярусное разбиение на отдельные опоры/острова** по высоте `10% / 50% / 90%` (Принцип Б) и читает **пользовательские метки частей** (`Vertex Groups`).
- **`Shift+V` (инженерная сводка):**
  - Точные крайние координаты по всем 6 сторонам (`Сверху +Z`, `Снизу -Z`, `Справа +X`, `Слева -X`, `Сзади +Y`, `Спереди -Y`), число вершин/рёбер/граней/открытых краёв и петель, список модификаторов и размеченных частей.

### Камера, освещение и рендер (`J`, `Shift+J`, `F10`, `Shift+F10`)
- **`J`** — отчёт по выбранному/захваченному объекту: попадает ли он в кадр камеры, какую долю кадра занимает, расстояние до камеры, какие источники света его освещают (на какую грань и на какой интервал падает свет) и куда ложится тень на уровне пола `Z = 0`.
- **`Shift+J`** — расширенная сводка по активной камере и всем источникам света в сцене (включая точное направление лучей `Солнца` относительно горизонта и проверку проволочных кривых).
- **`F10`** — выполнить рендер текущей камеры и озвучить итоговую композицию кадра.
- **`Shift+F10`** — сначала направить активную камеру ровно туда, куда вы сейчас смотрите, затем сделать снимок и озвучить кадр.

### Разделы и вкладки (`Shift+P` / `P`)
- Открывает удобное меню для быстрого переключения больших рабочих пространств Blender (`Layout`, `Modeling`, `Sculpting`, `Shading`, `Animation` и др.) и вкладок панели Свойств с автоматическим переходом в нужную зону.

## 5. Архитектура исходников

| Файл | Назначение |
| :--- | :--- |
| `blender_nvda_accessibility.cpp` | Точка входа DLL, перехватчики (`BLF_draw`, `draw_button`, `draw_menu_item`, `draw_aligned_panel`, `file_draw_list`, `button_activate_over`, `s_wndProc`), экспорты для Python |
| `blender_ui_types.hpp` | Структуры и флаги UI Blender 5.2, отслеживание живых попапов (`HasLivePopupRegionOnScreen`) и прямая очередь выполнения (`PostPendingUiActivation` / `ExecutePendingUiAction`) |
| `ui_button_query.hpp` | Чтение нативных подписей, значений, enum и подсказок кнопок, сортировка и управление списками зон (`StepButtonVector`, `ActivateCurrentZoneButton`, `CycleMainZone`) |
| `keyboard_hook.hpp` | Потоковый перехват клавиатуры (`WH_KEYBOARD`) для зон `0–3`, диалогов, меню, `Preferences` и `File Browser` |
| `nvda_speech.hpp` | Асинхронный речевой движок (фоновый поток Win32 → `nvdaControllerClient64.dll`), очистка текста и дедупликация |
| `pdb_resolver.hpp` | Быстрый однопроходный сканер `blender.pdb` и бинарный кэш смещений `blender_nvda_symbols.cache` (версия `3`, `33` символа) |
| `trampoline.hpp` | Безопасные x64-трамплины для установки перехватчиков на прологи функций |
| `BlenderNVDAInstaller.cpp` | Установщик: поиск Blender, безопасная замена DLL, копирование модулей, очистка `__pycache__`, предсборка кэша символов, `--rescan` / `--uninstall` |
| `blender_nvda_autoload.py` | Стартовый загрузчик аддона в Blender и привязка горячих клавиш `3D View` / `Object Mode` |
| `nvda_modules/*.py` | Модули 3D-навигации (`nav_3d.py`), RAM-сканера (`shape_scanner.py`), камеры и света (`camera_light.py`), разделов (`workspaces_ui.py`) и моста (`bridge.py`) |

## 6. Решение частых проблем

- **Blender запускается без озвучки:** проверьте, что запущен NVDA, рядом с `blender.exe` присутствует `blender.pdb`, а в `%APPDATA%\Blender Foundation\Blender\5.2\scripts\startup` лежат `blender_nvda_accessibility.dll`, `nvdaControllerClient64.dll`, `blender_nvda_autoload.py` и папка `nvda_modules/`.
- **После обновления Blender 5.2.x перестали работать перехваты:** закройте Blender и выполните `BlenderNVDAInstaller.exe --rescan`, чтобы пересобрать кэш символов под новый `blender.exe` / `blender.pdb`.
- **При переустановке остались старые файлы `.old`:** закройте все запущенные экземпляры Blender и повторно запустите `BlenderNVDAInstaller.exe` — он автоматически удалит старые `.old`-копии.
